---
description: "Link or refresh Jira work"
---

Use work-save to link an issue (the site can default from default_site) and jira-refresh for an explicit read. Configure the private connection as documented: basic auth with an API token for Jira Cloud, or a bearer token with an API base. Jira owns status/assignee/due; do not mirror editable execution fields or ask for credentials in chat.

Read `AGENTS.md` and `.ddt/runtime/WORKFLOWS.md`. Use its shared helper and revision/privacy rules. These commands are convenience entry points; the user can express the same intent naturally.
