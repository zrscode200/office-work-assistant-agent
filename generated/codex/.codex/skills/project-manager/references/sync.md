Read sync-status first. Pull only when authorized. Show exact destination, record changes, and message before publication; use the documented digest-checked publish command. Reconcile stale edits/divergence. Never stage all, force push, or send unrelated commits.

Read the workspace operating manual and `.ddt/runtime/WORKFLOWS.md`. Use its shared helper and revision/privacy rules. These commands are convenience entry points; the user can express the same intent naturally.
