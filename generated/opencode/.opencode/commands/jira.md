Use work-save to link an issue and jira-refresh for an explicit read. Configure approved API base/version and token environment name privately as documented. Jira owns status/assignee/due; do not mirror editable execution fields or ask for credentials in chat.

Read the workspace operating manual and `.ddt/runtime/WORKFLOWS.md`. Use its shared helper and revision/privacy rules. These commands are convenience entry points; the user can express the same intent naturally.
