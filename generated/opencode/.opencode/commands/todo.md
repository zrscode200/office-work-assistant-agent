---
description: "Track lightweight follow-ups"
---

Use work and work-save. Create local follow-ups with stable IDs; complete or reopen by changing status on that same record and revision. Link private follow-ups to projects without sharing. For Jira work use a reference and Jira-owned execution fields.

Read the workspace operating manual and `.ddt/runtime/WORKFLOWS.md`. Use its shared helper and revision/privacy rules. These commands are convenience entry points; the user can express the same intent naturally.
