## deepagents surface

Skills are in `.deepagents/skills` (`office-projects`, `office-notes`, `office-work`), selected by `.deepagents/skills.toml`; each skill's `references/` holds the workflow shortcuts and loads on demand. Run the helper with the shell tool from the workspace root. In Manual approval mode the user approves every helper call, so read what you need in one call where possible and never replace a rejected command with a different one. Record learnings in the workspace-root `AGENTS.md`, never in this managed file. A project hook in `.deepagents/hooks.json` reports open follow-ups at session start when the client trusts project hooks.
