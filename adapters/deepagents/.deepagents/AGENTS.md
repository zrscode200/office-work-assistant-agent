## deepagents surface

Skills are in `.deepagents/skills` (`office-projects`, `office-notes`, `office-work`), selected by `.deepagents/skills.toml`; each skill's `references/` holds the workflow shortcuts and loads on demand. Run the helper with the shell tool from the workspace root. Helper calls may need the user's approval: read what you need in as few calls as possible and never replace a rejected command with a different one. Record learnings in the workspace-root `AGENTS.md`, never in this managed file. A project hook in `.deepagents/hooks.json` reports open follow-ups at session start once the user allows project hooks.
